# 永續報告書生成系統（離線優先 PWA）

整合 TCFD、IFRS S1/S2、SASB 與台灣環境部/金管會法規的離線報告書生成工具。

## 核心特色

- **離線優先**：表單填寫、GHG 計算、合規檢查、Word 匯出完全不需連網
- **資料不外流**：所有資料儲存於瀏覽器 IndexedDB，永不上傳
- **雙引擎生成**：離線時用內建範本引擎，連線時可選 AI 智慧生成
- **可安裝**：PWA 技術，可安裝至桌面像原生 App 一樣使用
- **前端 Word 匯出**：直接在瀏覽器產出 .docx 檔

## 實務要點檢核表（分散於各章節底部）

各章節底部附有對應的實務檢核表，涵蓋專章撰寫的實務痛點：

- **重大性判斷底稿產生器**：一鍵產出可回應主管機關查核的底稿範本
- **財務影響衝擊路徑**：五步驟推演（事件鑑別 → 價值鏈環節 → 影響評估 → 因應決策 → 財務影響）
- **財會連結科目盤點**：對照各風險/機會的財務報表科目與勾稽表單（PO 單號等）
- **情境分析四大誤區檢查**：避免誤用情境、忽略差異、缺乏量化、工具選擇不當
- **韌性評估 vs 情境分析**：what if（工具）與 so what（解讀）之區分
- **內控與防漂綠檢核**：符合金管會 2025/1/1 起之內控要求
- **程序時程節點**：4/15 申報、股東會前 14 日、10 月底確信更正等法定時程

這些要點也整合進「合規檢查」的 23 項查核清單與離線範本引擎的生成內容中。

## 本地執行

因為 PWA 的 Service Worker 需要 HTTP(S) 環境（不能用 file://），請用簡易伺服器：

```bash
# Python
cd esg-pwa
python3 -m http.server 8000
# 開啟 http://localhost:8000

# 或 Node.js
npx serve
```

## 部署到網路（商品化）

### 靜態託管（最簡單）
直接上傳整個資料夾到任何靜態託管服務：
- **Vercel** / **Netlify** / **Cloudflare Pages**：拖曳資料夾即可，免費 HTTPS
- **GitHub Pages**：push 到 repo，開啟 Pages

因為全部是靜態檔案且離線運作，不需要後端伺服器，託管成本幾乎為零。

### AI 功能設定
兩種方式讓使用者使用 AI 生成：

1. **使用者自帶 Key**（目前設計）：使用者在「設定」頁填入自己的 Anthropic API Key，存於其瀏覽器。適合 B2B 或技術型使用者。

2. **後端代理**（需自建）：若要幫使用者付費呼叫 AI，需架設後端轉發 API（見下方）。此時修改 `app.js` 的 `callClaude()` 把網址改成你的後端。

```javascript
// app.js 中的 callClaude() 改為：
const resp = await fetch('https://你的後端.com/api/generate', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json', 'Authorization': 'Bearer ' + userToken },
  body: JSON.stringify({ section: sectionKey, data: this.state })
});
```

## 商業模式建議

| 方案 | 做法 |
|------|------|
| 免費版 | 純離線範本引擎，無 AI |
| 專業版 | 開放 AI 生成（使用者自帶 Key 或訂閱制後端代理）|
| 企業版 | 整包部署至客戶內網，資料完全不出企業防火牆 |

## 授權驗證（離線）

若要做離線授權碼，建議用非對稱加密：你用私鑰簽發授權碼，App 內建公鑰驗證。可用 Web Crypto API 實作，不需連網即可驗證授權有效性。

## 中英雙語與引用來源
